🔐 Panel de Nuestra Galaxia

⚠️ Falta conectar Supabase

Abre el archivo config.js del proyecto y pega tu Project URL y tu anon public key (los encuentras en Supabase → Project Settings → API). Luego sube el cambio con git push.

Iniciar sesión

Crea la cuenta del administrador con el correo y contraseña de arriba. Importante: después de crearla, desactiva los registros nuevos en Supabase → Authentication → Sign In / Up → "Allow new users to sign up".

Sesión: Ver la página 💖
